Данная программа (веб-платформа) предназначена для интерактивной отработки орфографических правил русского языка с использованием веб-фреймворка Flask и базы данных SQLite.

Вход пользователя осуществляется через окно (веб-страницу) с полями для электронной почты и пароля. Также реализована форма регистрации с указанием имени, логина, email и пароля.

При вводе данных пользователя происходит проверка в базе данных, при отсутствии пользователя создаётся новая запись с хешированным паролем (Werkzeug). Аутентификация управляется через Flask-Login.

После успешного входа открывается главное окно (главная страница) с выбором орфографических категорий для изучения (например, «Корни с чередованием», «Приставки ПРЕ и ПРИ», «Суффиксы», «Правописание НЕ» и др.) и возможностью начать тренировку.

Окно тренировки отображает слово с пропущенной буквой (символ подчёркивания вместо правильной буквы). Пользователь вводит одну букву в поле ввода и получает обратную связь: сообщение об успехе при правильном ответе или указание правильной буквы с отображением орфографического правила при ошибке. При неправильном ответе запись об ошибке сохраняется в базу данных (таблица user_mistakes).

Личный кабинет (профиль) содержит статистику ошибок пользователя, где все слова, вызвавшие затруднения, сгруппированы по категориям. Предусмотрена кнопка «Повторить», запускающая тренировку по проблемной теме.

Прогресс изучения (список допущенных ошибок) хранится в базе данных и обновляется при каждом неверном ответе. Защита от дублирования гарантирует, что одно слово сохраняется в ошибках только один раз.

Запуск программы производится командой python app.py (или через WSGI-сервер на виртуальной машине), где создаётся экземпляр приложения Flask, инициализируется база данных (SQLite), запускается веб-сервер (по умолчанию на порту 5000). Пользователь открывает браузер и переходит по адресу или публичному IP после развёртывания в Яндекс.Облаке.

Таким образом, программа сочетает удобный веб-интерфейс (адаптивный, на Bootstrap 5) и эффективный механизм хранения и обработки данных (SQLAlchemy ORM) для поддержки процесса изучения орфографии русского языка.

Она ориентирована на постепенную отработку правил, самоконтроль через тренировку с автоматической проверкой и работу над ошибками через личный кабинет с сохранением результатов в базе данных. Такое решение подходит для использования как в индивидуальном обучении (подготовка к ЕГЭ), так и для контроля знаний в учебных группах (например, на уроках русского языка в лицее).
